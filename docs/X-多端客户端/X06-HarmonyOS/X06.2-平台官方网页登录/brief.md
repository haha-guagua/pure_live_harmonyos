# X06.2 官方网页登录：任务书

## 来源和范围

用户2026-11-02发现“平台显示与授权→平台账号”缺少官方登录。上游wzgrx/PureLive fe4fdebf保留此功能，鸿蒙缺少WebView实现。已有X06.1修复和旧版应用、录像必须保留。

修改shared/in_app_web的账号能力与Cookie接口、平台登录桥接、account登录页，并注册非导出的WebLoginAbility承载原生ArkWeb；沿用原路由、核验逻辑与平台配置。通用网页搜索保持现有降级。保留B站扫码和Cookie手工导入；不改版本、上游更新源、main分支或签名材料。

## 验收

1. 对支持的9个平台显示原有官方登录入口；B站二维码页可切官方网页登录。
2. 真机可显示、触摸、缩放官方网页，页面历史与系统返回正常，失败可重试。
3. 原生读取HttpOnly登录Cookie，按既有规则核验并存入加密存储；返回账号页并在重启后保留。
4. 登录前及退出后清理目标平台的浏览器Cookie，不清除其他平台；取消登录不保存访客Cookie。
5. 证书错误和非网页协议拒绝；Cookie、账号、短信、密码不写日志或提交。

## 检查

Windows固定鸿蒙SDK中跑格式、严格分析、账号和Web桥接回归，构建并验签独立包名HAP。推送前完整gate.ps1 -All通过。真机先检查匿名登录页面和返回；用户自行完成真实登录，后续再核对加密持久化及退出。页面可见不等于账号登录通过。
