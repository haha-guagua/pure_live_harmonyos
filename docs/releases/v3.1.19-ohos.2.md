# Pure Live HarmonyOS v3.1.19-ohos.2

鸿蒙实验预览版，基于上游 `liuchuancong/pure_live`，应用版本 `3.1.19+4108`。提供同一构建的调试签名包和未签名包，均不是通用正式安装包。

## 新增与修复

- 修复 Windows PowerShell 将签名工具警告误判为构建失败的问题，校验依据为工具退出码。
- `v3.1.19-ohos.1` 仅有失败的发布任务，没有发布安装附件；本版本完成首批双包发布。

- 接入 HarmonyOS 原生播放器、网络检测、路径与偏好存储。
- 修复原生资产漏打包导致的播放器解码失败。
- 修复全屏按钮、横竖屏切换及系统返回处理。
- 支持全屏左右滑动调节窗口亮度和应用音量，退出直播间后恢复系统亮度策略。
- 接入鸿蒙 FFmpeg 录制与 MP4 合并，固定 AKI 桥接依赖，修复录制启动崩溃。

## 验证范围

2026-10-20 在 Mate 90 Pro / HarmonyOS 7.0.0.109 SP11 / API 26 上完成部分实机验证：斗鱼播放、全屏、亮度音量手势、短录制、停止和 MP4 回放。测试录像约50秒、13.70 MB。21项隔离兼容测试通过，受影响 Dart 文件聚焦分析通过。

这些历史设备证据对应修复提交 `b21507e`；发布流程产生的新包不会自动继承“已在真机测试”的结论。

## 已知限制

- 其他站点、HLS、长期/后台录制、断流重连仍待验收。
- 系统媒体会话、画中画、投屏等未验收。
- 仓库仍有既存的录制本地播放器跨域引用架构检查问题。
- 最低 API 20，目前只在 API 26 手机验证。

## 安装与升级

| 安装包 | 使用条件 |
| --- | --- |
| `*-debug-device-signed.hap` | 已完成设备限定调试签名，仅 profile 登记设备可直接安装 |
| `*-debug-unsigned.hap` | 未签名，不能直接安装，需使用自己的证书和设备 profile 签名 |

两种包的应用内容一致。签名包内嵌验证证书/profile及设备绑定信息，不包含私钥或口令；未签名包适合有签名能力的开发者。两种包均为 Debug 构建，未签名不代表 Release 构建。

从附件下载所需包，校验 SHA-256 后通过 HDC 或 DevEco Studio 安装。设备必须包含在调试 profile 中。相同包名与兼容签名可覆盖更新；安装失败请先查错误，不要直接卸载。

详细步骤与附件说明见随包 `INSTALLATION.md` 或仓库 [安装说明](https://github.com/haha-guagua/pure_live_harmonyos/blob/main/docs/INSTALLATION.md)。源码压缩文件不能直接安装。
